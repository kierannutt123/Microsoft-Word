# Microsoft Word
An end-user reference covering key Microsoft Word tools and features.

## Ribbon Tabs
![Home](Word%20Ribbon.png)

### Other Ribbon Tabs
##### File
Open, save, print, share, and manage documents.

#### Insert
Add tables, pictures, links, headers, page numbers, and other content.

#### Design
Change the overall look of the document using themes, colours, and fonts.

#### Layout
Adjust margins, orientation, spacing, columns, and page layout.

#### References
Create contents pages, citations, footnotes, captions, and bibliographies.

#### Mailings
Create mail merges, labels, and envelopes.

#### Review
Check spelling and grammar, add comments, and track document changes.

#### View
Change document views, zoom, rulers, and the Navigation Pane.

#### Help
Access Word help, support, and training.

### Additional Features
#### Developer Tab

Provides access to advanced Word features including form controls, macros, add-ins, and Visual Basic for Applications (VBA).
