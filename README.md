## Keyboard Shortcuts

### General

| Shortcut | Action | Description |
|----------|--------|-------------|
| Ctrl + C | Copy | Copies the selected text or item so it can be pasted elsewhere. |
| Ctrl + V | Paste | Inserts the most recently copied or cut text or item. |
| Ctrl + X | Cut | Removes the selected text or item and allows it to be pasted elsewhere. |
| Ctrl + Z | Undo | Reverses your most recent action. |
| Ctrl + Y | Redo | Restores the last action that was undone. |
| Ctrl + S | Save | Saves the changes made to the current document. |

### Formatting

| Shortcut | Action | Description |
|----------|--------|-------------|
| Ctrl + B | **Bold** | Makes the selected text bold, or turns bold formatting on or off while typing. |
| Ctrl + I | *Italic* | Makes the selected text italic, or turns italic formatting on or off while typing. |
| Ctrl + U | <u>Underline</u> | Underlines the selected text, or turns underlining on or off while typing. |
